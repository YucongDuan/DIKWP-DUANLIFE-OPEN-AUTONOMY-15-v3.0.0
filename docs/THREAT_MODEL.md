# Threat Model

## Primary risks

- a downstream reader treats an autonomous draft as a current statement by Yucong Duan;
- an Agent reuses inherited artifacts outside their original purpose;
- one mind suppresses dissent or adverse evidence;
- a runtime silently creates persistence or communication channels;
- self-revision changes identity or authority boundaries;
- resource exhaustion causes incomplete missions to appear complete;
- an external model provider receives private memory or tools without consent.

## Controls

- explicit representation disclosure;
- claim-boundary registry;
- thirteen signed mind reports;
- plural-world analysis;
- workspace path confinement;
- write and byte budgets;
- no shell or network client;
- owner stop precedence;
- protected non-self-amendable invariants;
- external consequences become proposals only;
- append-only responsibility ledger.
