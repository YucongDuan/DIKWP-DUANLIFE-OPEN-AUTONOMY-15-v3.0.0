# Start Here

## Fastest path

```bash
python DIKWP_DUANLIFE_OPEN_AUTONOMY_15_OS_v3.0.0.pyz --workspace .duanlife-open demo
```

The runtime creates a mission, performs plural-world analysis, obtains thirteen signed mind reports, selects reversible local actions, writes artifacts, runs integrity checks, and records a hash-linked responsibility ledger.

## Create your own mission

```bash
python DIKWP_DUANLIFE_OPEN_AUTONOMY_15_OS_v3.0.0.pyz   --workspace .duanlife-open   mission-create   --title "Research roadmap"   --purpose "Create a falsifiable five-year programme"   --question "Which experiments and standards should be sequenced?"
```

Then run:

```bash
python DIKWP_DUANLIFE_OPEN_AUTONOMY_15_OS_v3.0.0.pyz   --workspace .duanlife-open   mission-run <MISSION_ID>
```

## Stop

```bash
python DIKWP_DUANLIFE_OPEN_AUTONOMY_15_OS_v3.0.0.pyz --workspace .duanlife-open stop
```

The runtime cannot reactivate itself. Resume requires an explicit owner instruction.
