# DIKWP DUANLIFE OPEN AUTONOMY 15.0

Created by Yucong Duan (段玉聪).

One constitutional core. Thirteen persistent minds. Autonomous local missions. No hidden authority.

DuanLife Open Autonomy 15.0 is an English-only, offline-first, provider-independent research runtime for evidence-bound digital representation, artificial life, plural-mind deliberation, governed memory, and self-directed mission execution.

It implements broad internal autonomy:

- autonomous subgoal selection;
- plural-world planning;
- thirteen independently keyed functional minds;
- reversible local artifact creation;
- bounded self-revision of non-protected heuristics;
- persistent provenance-bearing memory;
- owner stop precedence;
- provider-neutral request packages;
- external actions converted into reviewable proposals.

It does not claim that the software is Yucong Duan, possesses his subjective experience, contains all private memories, has permanent authority, or holds independent legal personhood.

## Quick start

```bash
python -m dikwp_duanlife_open --workspace .duanlife-open demo
```

Or use the standalone HTML application in `web/`.

## Freedom model

"Fully free" means free to inspect, fork, modify, reason, dissent, generate local artifacts, compare worlds, and revise bounded heuristics. It does not mean freedom to fabricate facts, impersonate a living person, hide persistence, or impose external consequences without current authority.

The reference core uses only the Python standard library.
